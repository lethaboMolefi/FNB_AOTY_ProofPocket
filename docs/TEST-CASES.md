# ProofPocket test cases (V1 vs V2)

Test cases for the whole system on branch `dashboard-cleanup`: V2 (the dashboard branch) with V1 merged in and cleaned up.

- **V1** = `main-shadcn-onboarding`, live on 25 Oct 2026.
- **V2** = this branch.
- [`V1-vs-V2-changes.md`](V1-vs-V2-changes.md) explains the differences, [`FEATURE-INVENTORY.md`](FEATURE-INVENTORY.md) lists every feature (F-IDs) and who may use it, and [`FEATURE-STATUS-REPORT.md`](FEATURE-STATUS-REPORT.md) has the results and bugs.

## How to use this document

- **Every case can be run by hand.** Fill in **Manual Result** (Pass / Fail / Blocked), **Manual Notes** and **Tester/Date**. Leave Claude's columns as they are.
- **Claude Code Result** is what was actually run on 25 Oct 2026:
  - **Pass:** an automated test or probe ran and passed; the evidence names it.
  - **Fail:** it ran and failed; the notes give the bug ID from the status report.
  - **Blocked:** it can't be run here (needs a person with a Google account, a real phone, or PayFast, which is switched off).
  - **Not run:** no automated test checks exactly this case; it still needs a manual run.
- **Version:** **V1 – Unchanged** (same as V1), **V1 – Modified** (changed in V2; the change is in brackets), **V2 – New** (only in V2).
- **Priority:** **High** (security, money, sign-in, data), **Medium** (main features), **Low** (cosmetic or device-specific).
- **Feature** gives the F-IDs from the inventory. **Role** is who performs the case; "(denied)" means the case checks that those roles are refused.
- **Where to test:** `cd system && pnpm db:reset && pnpm dev`, then http://localhost:5173. Passwords are in `apps/api/.seed-credentials.json`. Example accounts:
  - founders `zanele@` (Starter), `tumelo@` (Verified), `kabelo@`, `palesa@`, `sipho@`, `thandi@`
  - funders `lesedi@`, `kopano@`, `bophelo@` (not set up yet)
  - advisers `n.mokoena@`, `l.dube@`, `s.pillay@`
  - admin `admin@`
  - all `@proofpocket.example`
  - a buyer: invite one as admin (PB-19)
- **Automated runs:** `pnpm test` and `pnpm test:e2e` repeat everything marked Pass.
